**Subject:** Freedom of Access Act request – residential building permit records, 2008–present

To the Records Officer / Code Enforcement Office,

Under Maine's Freedom of Access Act (1 M.R.S. §§ 400–414), I request copies of the following public records:

**Records requested**
Building permit records for **one- and two-family residential properties** in the City of Bangor for permits **applied for or issued from January 1, 2008 to the present**, for work on **roofs** (re-roofing, roof replacement, roof covering, or structural roof repair).

If the permit system cannot isolate roofing work, please provide **all residential building permits for existing buildings** (e.g., permit type "CONST EXIS" or equivalent) for the same period, **including the work description field**, so roofing permits can be identified from the description.

**Fields requested, where they exist**
- Permit number
- Permit type / category
- Description of work
- Application date, issue date, and final/closed date
- Permit status
- Property address
- Map-lot and/or tax account number
- Owner name at the time of the permit
- Contractor name

**Format**
I request the records in **electronic form**, preferably a spreadsheet export (CSV or Excel) from the permitting system, sent by email or file link. I don't need copies of plans, applications, or other attachments; a data export of the fields above is enough.

**Fees**
Please let me know in advance if fees will exceed **$50**. If any part of the request would be costly, I'm glad to narrow it; for example, by starting with permits from 2015 to the present.

If any part of this request is denied, please cite the specific exemption and release any parts that are not exempt.

Thank you for your help. I'm happy to discuss the request by phone or email if that would make it easier to fulfill.

Sincerely,

[Your name]

### Notes for you (don't send this part)
- **Timing:** the law requires the city to acknowledge the request promptly (within a few business days) and give a good-faith estimate of when it will respond. Simple data exports often arrive in 1–4 weeks.
- **Why 2008:** your scoring rule is "no roof permit since 2008". The city's public map only has permits from 2014 to Jan 2020, with no work description, so this request fills 2008–2013 and 2020–today and separates roofs from decks, windows, etc.
- **When it arrives:** save it as `data/roof_permits.csv`. The scoring needs an `account` column (tax account number) and a `permit_year` or `permit_date` column. If the city sends addresses instead of account numbers, send me the file and I'll match it to the parcels.
- **Also ask on the call:** does Bangor require a permit for a re-roof, including shingling over one existing layer? If overlays are exempt, some re-roofs won't appear in the records.
